视频相关知识

2026-10-15
ffmpeg

单位解释：

  1. 色深 Bit Depth 每个色彩通道使用几个bit来表示，比如8bit，10bit，12bit等。
  2. 色度采样 Chroma Subsampling 计算机先把 RGB 转换为 YUV 格式，再进行色度采样。
  • Y: 亮度
  • U: 蓝色差(B—Y)
  • V: 红色差(R—Y) 4:2:2 表示u，v通道采样率各自使用2个像素 4:2:0 表示u,v通道采样率共同使用2个像素
  1. 像素格式 Pixel Format 这是把色深和色度采样合起来的写法，比如 yuv420p，yuv420p10le这类，作为一种固定的组合模式。 yuv420p = YUV + 4:2:0 + 8bit + planar（平面） yuv420p10le = YUV + 4:2:0 + 10bit + 小端存储 nv12 = YUV + 4:2:0 + 半平面（Y 一块，UV 交错一块）→ 硬件编解码用这个 rgb24 = RGB + 8bit × 3通道，无压缩 p010 = 10bit 的 nv12，硬件 HDR 用

amd 硬件解码

amd 硬件解码文档 加速卡和主机是不同的硬件，其数据是不能直接相互访问的，必须通过pice来传输，当需要cpu处理时，就需要相互通信

vf 视频过滤器 video filter

一条串行滤镜链，用逗号连接，前一个的输出接后一个的输入 -vf "A,B,C" 表示 A -> B -> C 依据顺序

hwdownload_ama：把数据从卡上搬回主机内存

卡上内存 ──DMA──> 主机内存        ("download" = 下载到主机)

官方实例

ffmpeg -y -hwaccel ama -c:v h264_ama -out_fmt nv12 -i <in> \
  -vf hwdownload_ama,format=nv12 -f rawvideo /tmp/dec_out.nv12
#     ↑ 搬回主机        ↑ 声明搬回来之后的像素格式

当需要主机来处理数据时，就需要使用这个参数，需要添加format=format 来表示硬件解码的像素格式，这和开始的-out_fmt 是一致的，必须一致，否则会报错。

hwupload_ama：把帧从主机内存传回卡上

主机内存 ──DMA──> 卡上内存        ("upload" = 从主机上传)

当主机处理完成后，如果需要硬件继续处理，就需要使用这个参数，将数据回传到卡上。

10bit和8 bit转化的问题

当使用 -c:v h264_ama 使用硬件编码时，使用-pix_fmt不生效，硬件不支持额外的参数输入，如何解决呢？ 去修改-out_fmt也会报错，因为ama默认不会去转化,恰好使用了vf用处理的，所以可以使用vf来处理

-vf "hwdownload_ama,format=yuv420p10le,format=yuv420p,scale=1920:1076,hwupload_ama"

第一个format表示从卡上搬回来的像素格式，第二个format表示主机处理后的像素格式，这样就可以在主机上处理10bit的视频，然后在卡上编码8bit的视频
