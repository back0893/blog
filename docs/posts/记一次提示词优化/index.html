记一次提示词优化

对话机器人的提示词之前存在问题，其问题就是3个大类

  1. 幻觉 回答中经常出现脱离人物卡，上下文和记忆，进行扩充回答，模拟不存在的场景对话
  2. 突破界限 回答中出现攻击性语言，攻击性的嘲讽
  3. 注意力涣散，对话达到5轮以后，开始出现重复回答，或者突破界限
  4. 主动性或者质量不足，回答无法引起对话人兴趣，主动的继续对话

优化过程

  1. 加入cot思维链 使用提示词，引导模型进行cot思维，避免出现幻觉和突破界限，同时提升回答的质量，让对话人有继续的兴趣 问题：太慢了，加入cot后，回答速度变慢了，因为需要等到其cot思维完成，才能将回答返回给对话人

  2. 优化回答速度 分析之前的提示词，就是cot思维链，其思考过程太多，太复炸，将本再上下文中的信息，也作为思考信息，导致回答速度变慢 对cot思维链进行删除，删除原本可以通过上下文直接回答，只保留 2个部分（用户说了什么 / 角色该怎么回答）

  3. 回答格式不被模型遵守 思维链的思考回答和回答，都需要被模型输出，然后结构，输出给对话人。其中思考过程可以被忽略，只保留回答。但是在提示词边长后，模型 遵守回答格式明显出现异常或者遗忘的情况。这样就需要进行调整，目前是在system提示词的最后部分，追加一个输出的格式，使用少量样本来 让模型学习回答的格式。解析器实现为一个稀疏解析器，不需要全闭合，只需要解析出开始标签就可以输出

<think>
[思考内容]
</think>
<response>
[回答]
</response>

  1. 优化提示词，减少提示词的长度 为了对回答和场景等进行限制，在不停的加入规则，伴随提示词的长度增加，其约束效果没有提示，反而在变弱还在拖累回答速度 而且还出现了，规则之间的冲突，导致模型在规则之间进行切换，不遵守任何规则。 这就很简单了，优化提示词，减少规则的数量，减少规则的复杂度，同时规则的重要程度排序，先遵守重要的规则，再遵守不重要的规则。

  2. 为什么不使用少量样本？ 因为少量样本，提供给模型学习，会导致一个问题，模型回答基本和样本回答一致，没有变化，在对话机器人的场景，导致互动性和变化性不够好

  3. 优化动态提示词 对于动态提示词，需要根据对话人的问题，动态的生成提示词，其中部分原本内容为空的部分，直接删除。而不是输出空字段 这样也可以避免模型被空字段所干扰，导致回答的格式被改变。

  4. 加入自检提示词 最后使用一个闸门，作为最后检测提示词，让模型最其输出内容在输出前，进行一次自检，确保其输出的内容符合要求。
